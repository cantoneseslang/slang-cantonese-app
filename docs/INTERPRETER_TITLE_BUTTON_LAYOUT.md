# 通訳モード：タイトルと3ボタンは重ねない

何度も直した確定レイアウト。浮きボタンや使用回数を足しても、タイトルを上げて逃げるな。

## 確定位置

- **タイトル**（カントン語通訳 / 中国語通訳 / 日本語通訳）
  - モバイル: `bottom: calc(env(safe-area-inset-bottom) + 1.8rem)`
  - デスクトップ: `bottom: 3.75rem`
  - 画面下に置く。上げると3ボタンと重なる。
- **お願い・マイク・ミュート**
  - モバイル: `bottom: calc(env(safe-area-inset-bottom) + ${button直径rem + 3}rem)`
  - デスクトップ: `bottom: calc(7.5rem + ${buttonDiameter}px)`
  - タイトルより上。`+3rem` / `7.5rem` は重なり解消の確定値（ca26eab）。

## 禁止

- タイトルの `bottom` を大きくして浮きボタンや使用回数を避ける
- 3ボタンの `bottom` を `+3rem` より下げる
- 全部のモードのアイコン色をまとめて変える。薄い赤は広東語→日本語のときだけ

## 香港→日本の浮きボタン

- 先生連絡と同じ左下。`document.body` に出す
- タイトルは中央のまま動かさない
